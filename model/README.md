# 本地模型

应用运行时从 EXE 同目录的 `model` 文件夹读取：

- `4x-UltraSharpV2.pth`：UltraSharp V2，DAT 4×。
- `ScuNET.pth`：SCUNet 1× 去噪。

公开源码和默认 CI 产物不附带这两份预训练权重。请自行取得相应模型，并保留上述文件名放入本目录。源码运行时使用项目根目录下的 `model`。

包含权重的便携构建需要显式传入 `build.ps1 -IncludeModels`。向公众分发权重前需单独确认模型许可；应用的 AGPL 许可不替代权重许可。

CI 中生成的未训练测试权重只用于验证推理流程，不会纳入发行包，也不能作为图像质量模型使用。
